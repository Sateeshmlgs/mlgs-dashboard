# MLGS - Home Accessories Dashboard

A professional, modern business dashboard for managing inventory (Stocks) and financial performance.

## Features
- **Stocks Module**: Manage inventory with real-time search, voice input, and high-quality photo capture.
- **Finance Module**: Track revenue, expenses, and net profit with interactive Chart.js visualizations.
- **Advanced Interaction**: Voice-to-text product naming and camera integration for product photography.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## Tech Stack
- HTML5 / CSS3 (Vanilla)
- JavaScript (ES6+)
- Chart.js
- Font Awesome
- Web Speech API
- MediaDevices API (Camera)
